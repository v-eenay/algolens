# ProGyan AlgoLens - AI Service

LangChain-based AI explanation service for ProGyan AlgoLens.

## Features
- **Contextual Explanations**: Generate step-by-step logic explanations based on execution state.
- **Adaptive Learning**: Adjust explanation difficulty (Beginner, Intermediate, Advanced) based on user profile.
- **RAG Implementation**: Retrieve algorithm concepts from a specialized knowledge base (Pinecone).
- **Multi-LLM Support**: Primary GPT-4 with Claude fallback.
- **Collaborative Assistance**: AI-driven insights for shared algorithm development.

## Tech Stack
- **Framework**: LangChain
- **Models**: OpenAI GPT-4, Anthropic Claude
- **Vector Store**: Pinecone
- **Logic**: Custom prompt engineering with adaptive learning feedback.
