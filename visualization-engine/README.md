# ProGyan AlgoLens - Visualization Engine

TypeScript-based visualization library for ProGyan AlgoLens.

## Features
- **Data Structure Renderers**: Specialized renderers for Arrays, Trees, Graphs, and Hash Tables.
- **Animation System**: Smooth transitions and highlights driven by execution frames.
- **Interactive Layouts**: Force-directed graphs and auto-positioning tree structures.
- **Shared Workspaces**: Sync state across collaborative sessions.
- **D3.js & React Flow**: Powered by industry-standard visualization tools.

## Components
- **RenderPipeline**: Handles the flow from raw execution state to visual nodes.
- **AnimationController**: Manages playback speed, stepping, and frame interpolation.
- **LayoutManager**: Calculates optimal positioning for complex data structures.
